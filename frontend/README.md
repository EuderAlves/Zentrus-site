# Frontend Zentrus Tecnologia

Projeto React + Vite com rotas dedicadas e organizacao por responsabilidade.

## Pastas principais

```txt
src/app/          Configuracao das rotas da aplicacao
src/components/   Componentes reutilizaveis
src/data/         Textos e conteudos exibidos nas paginas
src/hooks/        Regras de tela reutilizaveis
src/pages/        Paginas acessadas por rota
src/services/     Comunicacao com APIs externas ou backend
src/styles/       CSS global da aplicacao
src/types/        Tipos TypeScript compartilhados
```

## Rotas

```txt
/           Home
/servicos   Pagina de servicos
/solucoes   Pagina de solucoes
/processo   Pagina de processo
/orcamento  Pagina de orcamento
```

## Scripts

```bash
npm run dev
npm run lint
npm run build
```
